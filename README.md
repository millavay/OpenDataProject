# 🌍 MoveMatch Europe

**Find the country that fits you.**

MoveMatch Europe is a web application developed for our **Open Data course**. It helps students and people planning to relocate discover European countries that best match their preferences using publicly available data.

Instead of searching across multiple websites, users can compare countries based on factors such as living costs, employment opportunities, climate, and education.

## ✨ Main Features

- 🎓 **Personalized Profiles** – Choose between studying abroad and relocating.
- 💰 **Budget & Preferences** – Set your budget and select what matters most.
- 🌍 **Country Recommendations** – Discover European countries matching your priorities.
- 📊 **Country Comparison** – Compare destinations using real statistics.
- 🔎 **Transparent Results** – Understand why each country was recommended.

## 📊 Open Data Sources

Our project plans to use publicly available European datasets:

- [Eurostat](https://ec.europa.eu/eurostat) – Living costs, unemployment, and housing indicators.
- [EUROSTUDENT](https://www.eurostudent.eu/) – Student living conditions and expenses.
- [Eurydice](https://eurydice.eacea.ec.europa.eu/) – Education and tuition-fee information.
- [Open-Meteo](https://open-meteo.com/) – Historical weather and climate data.
